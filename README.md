# Система учёта и анализа выбытия КРС (ОАО «Новая Припять»)

Веб-приложение на Flask + SQLite для оперативного зооветеринарного учёта выбытия крупного рогатого скота, мертворождений/абортов, аналитики и выгрузки отчётности (Формы 209-АПК / 210-АПК, AITS, Excel-матрицы).

## Быстрый старт

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 create_users.py
python3 app.py
```

Приложение запускается по адресу `http://127.0.0.1:3000` (или через `APP_PORT`).

## Первичная инициализация и безопасность

- **Секретный ключ**: задаётся через переменную окружения `SECRET_KEY`. Если она не установлена, при первом запуске автоматически генерируется криптографический ключ в `instance/.secret_key` (не хранится в репозитории).
- **Первичный администратор**: `create_users.py` создаёт учётную запись `admin` **только если таблица `users` пуста**. Временный пароль берётся из `INITIAL_ADMIN_PASSWORD` либо генерируется случайно и записывается в `instance/initial_credentials.txt`. При первом входе система принудительно перенаправляет на смену пароля (`/change_password`).
- **CSRF-защита**: включена по умолчанию (`WTF_CSRF_ENABLED=True`), работает с `ProxyFix` и HTTPS-куками.
- **Переменные окружения** (см. `.env.example`):
  - `SECRET_KEY` — секретный ключ подписи сессий Flask;
  - `INITIAL_ADMIN_PASSWORD` — временный пароль первичного администратора при пустой БД;
  - `DATABASE_PATH` — путь к файлу SQLite (по умолчанию `cattle_disposal.db`);
  - `APP_PORT` — порт HTTP-сервера (по умолчанию `3000`);
  - `WTF_CSRF_ENABLED` — включение CSRF-защиты (`True` по умолчанию).

## Архитектура

- `app.py` — фабрика приложения, CSRF, ProxyFix, динамическая защита cookies для HTTPS, заголовки безопасности и rate-limiting;
- `domain.py` — единый доменный слой: нормализация и валидация дат, расчёт фаз лактации (`compute_lactation_phase`), классификация систем патологий (`classify_pathology_system`), валидация числовых и формальных ограничений записей;
- `database.py` — инициализация и миграции SQLite (WAL, единые индексы, атомарная генерация `cow_id` / `record_code` с поддержкой переиспользования активной транзакции);
- `cow_queries.py` — SQL-построитель фильтров и общие функции вставки записей;
- `auth.py`, `routes/` — аутентификация (IP-ограничение попыток без username-DoS, смена пароля), CRUD коров и мертворождений, импорт Excel/CSV, генерация отчётов и администрирование.
